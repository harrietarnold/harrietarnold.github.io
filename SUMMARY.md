## 🔧 Customization Tips

### Change Colors
Edit `/css/style.css`, line 2:
```css
:root {
    --bg-primary: #0F1720;     /* Change main background */
    --accent-blue: #4F6D8A;    /* Change accent color */
    /* etc */
}
```

### Update Artist Info
Edit `/artists/{artist-name}.html`:
- Change event venue and date (artist-info section)
- Update "Behind the Show" description
- Ensure hero image path is correct

### Add New Artist
1. Duplicate `/artists/fontaines-dc.html`
2. Update all text and image paths
3. Add link to homepage artists grid
4. Update prev/next navigation in other artists

### Modify Fonts
Edit the Google Fonts link in `<head>` of any HTML page:
```html
<link href="https://fonts.googleapis.com/css2?family=YourFont:wght@400;600;700&display=swap" rel="stylesheet">
```
